# AI Integration Layer

This folder is reserved for the final AI inference implementation.

The frontend currently uses a local prototype generator so the project runs without credentials. For the Snapdragon challenge submission, connect this layer to the selected Qualcomm/Snapdragon-compatible on-device model/runtime and record:

- Device/platform
- Model name and version
- Runtime/toolchain
- Quantization, if applicable
- Latency and memory observations
- Example inputs/outputs
